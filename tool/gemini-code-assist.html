Overview
Gemini Code Assist is Google's AI-powered coding assistant, built around the Gemini model family and Google Cloud's identity and security tooling. As of mid-2026, the service underwent a major transition: on June 18, 2026, the IDE extension and Gemini CLI stopped serving free-tier and Google AI Pro/Ultra subscribers, who were migrated to Antigravity and Antigravity CLI. Gemini Code Assist Standard and Enterprise editions continue to be available for organizations. The tool targets long-context work with a 1,000,000-token context window that can absorb substantial portions of a repository into a single prompt, making it suitable for cross-file refactors and pattern audits. The Enterprise tier adds code customization that can index up to 20,000 private repositories from GitHub, GitLab, or Bitbucket for organization-specific suggestions. The free tier previously offered 180,000 completions per month and 1,000 agent/CLI requests per day, though the free offering now routes through Antigravity for individuals.
✅ Benefits
  • Million-token context window handles large monorepo questions and cross-file refactors without separate retrieval steps
  • Enterprise tier supports VPC Service Controls, IAM, and federated identity, plugging into existing Google Cloud governance
  • Free tier remains generous relative to competitors with 180,000 completions/month for personal use via Antigravity
⚠️ Drawbacks
  • Product direction shifted in June 2026: free users must migrate to Antigravity, creating uncertainty about the legacy Gemini Code Assist experience
  • Standard and Enterprise editions require a Google Cloud project and sales engagement, making adoption complex for individuals
  • Best suited for Google Cloud-aligned teams; value drops outside that ecosystem
