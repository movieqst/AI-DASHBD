Overview
Kimi is Moonshot AI's long-context assistant, built around a series of open-weight Mixture-of-Experts models. The newest flagship, Kimi K3 (released July 16, 2026), is a 2.8-trillion-parameter model with native multimodal (text/image/video) understanding, always-on "thinking mode," and a 1-million-token context window — currently the largest open-weight model released to date. API pricing for K3 is $3 per million input tokens and $15 per million output tokens (with a discounted $0.30 cache-hit rate). Earlier generations (K2.5, K2.6) remain available at lower cost and power the consumer Kimi app and Kimi Code CLI, an open-source terminal coding agent. Moonshot is backed by Alibaba and Tencent and has raised roughly $2B+ at a valuation climbing toward $20B.
✅ Benefits
  • Exceptionally long context window (up to 1M tokens) makes it strong for analyzing large documents, codebases, or long conversations in a single prompt
  • Open-weight availability and aggressive API pricing make it one of the most cost-effective frontier-class options for developers
⚠️ Drawbacks
  • Full open-weight downloads for the newest model (K3) lag behind the API launch, so local/self-hosted deployment isn't immediately available at release
  • English-language polish and Western-market documentation/support are less mature than U.S.-based competitors, reflecting its origin as a China-first product
